# Previous results from the uploaded project

`previous_results/` preserves the existing Stim, JSON, SVG and formula files from
the uploaded Code directory. These are historical results, not outputs of the
new workflow. Their record numbering may differ from freshly simplified circuits.

Run the new main.py to generate current results under `outputs/demo/`.
Original explanatory notes and old main scripts (as text) are in `docs/legacy/`.
The source archive omits Git internals and Python bytecode. Keep your existing
checkout's `.git` directory when adopting this source layout.
